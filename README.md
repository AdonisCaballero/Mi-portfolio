# Portfolio – Adonis Caballero

Bienvenido a mi portfolio personal web, donde podrás ver un poco de mí, mis conocimientos, como trabajo y algunos de mis proyectos.



## Qué incluye

* **Sobre mí:** presentación breve del perfil y de cómo trabajo.
* **Tecnologías:** Java, Kotlin, JavaScript, SQL, Spring, JSON y XML.
* **Proyectos:** enlaces a mis proyectos destacados en GitHub, como el libro de recetas estilo Minecraft y el creador de Pokémon.
* **Formación:** CFGS DAM en el IES El Rincón e inglés B2.
* **Contacto:** correo electrónico, con botón para copiarlo.

## Cómo verlo

Abre el archivo `portfolio-adonis.html` en cualquier navegador. No necesita instalación ni dependencias.

## Detalles técnicos

* Página estática hecha con HTML, CSS y JavaScript, sin frameworks.
* Tema claro y oscuro, con botón para cambiar entre ambos.
* Diseño adaptable a móvil y ordenador.
